# Game Setup Kit player guide

The offline Windows x64 demo is the easiest way to try setup. It includes a small example game and all of the demo’s extra files. The standard demo is for trying the local-file prompt.

1. Download the [offline demo ZIP](https://github.com/goodtripgoodtip/GameSetupKit/releases/download/v0.8.1/GameSetupKit-Windows-Demo-Offline-v0.8.1.zip).
2. In File Explorer, right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and double-click **GameSetupKit-Demo-Setup-Offline.exe**. It was tested on Windows 11.
4. Follow **Continue**, review the choices and terms, then choose **Install**. Choose **Play Now** when setup finishes.

## Finding the original game

The demo supplies its own example files. A real Steam mod needs the supported Steam release of the original game. If setup can’t find it, right-click the game in your Steam Library, choose **Manage**, then **Browse local files**. Back in setup, choose **Find game** and select that folder.

## Missing files or a paused install

- For a missing extra, use **Choose file** or **Choose folder**. When the standard demo asks for `optional-scene.txt`, select it from the **Demo files** folder beside Setup.
- If setup pauses, choose **Retry**. Verified downloads and completed preparation can be reused.
- To report a problem, open **Show setup details** and use **Copy details**. Review the text for personal file paths before sharing it.
- If Windows warns about the installer, check that your download came from the [official release](https://github.com/goodtripgoodtip/GameSetupKit/releases/tag/v0.8.1). The installer is unsigned. Keep Windows protections enabled. If you’re unsure about the file, stop and report what Windows showed.

## Remove the demo

Reopen Setup, select **Uninstall**, and review what will be removed. Removal starts after the final confirmation. Your demo saves and unrelated files are kept.
